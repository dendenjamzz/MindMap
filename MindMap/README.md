# MindMap

MindMap is a lightweight mind-mapping app with email-confirmed accounts, MySQL persistence, and a Flask-based NLP helper for generating node suggestions.

## Stack
- Frontend: static HTML/CSS/JS served by Express
- Backend: Node/Express with MySQL and Nodemailer
- NLP helper: Flask service consumed by `/process-words`

## Setup
1. Requirements: Node 18+, Python 3.10+, MySQL 8+.
2. Copy `mindmap-backend/.env.example` to `mindmap-backend/.env` and fill values.
3. Install backend deps: `cd mindmap-backend && npm install`.
4. Install Python deps (for Flask): activate your venv, then `pip install -r requirements.txt` (if present) or ensure Flask + needed libs are installed.
5. Run Flask helper: `python flask_server.py` in `mindmap-backend`.
6. Run Node backend: `npm start` in `mindmap-backend`.

## Environment variables (backend)
- `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
- `EMAIL`, `EMAIL_PASSWORD`
- `APP_URL` (public URL for confirmation links)
- `FRONTEND_ORIGIN` (comma-separated allowed origins for CORS)
- `FLASK_URL` (e.g., `http://127.0.0.1:5000/process`)
- **`JWT_SECRET`** – a strong random string used to sign authentication tokens. **Do not** commit it; set in production.


## Notes
- Database tables auto-provision on startup.
- Email confirmation is required before login succeeds.
- JWT tokens are now issued on login and must be sent in the `Authorization: Bearer <token>` header for protected endpoints (`/save-constellation`, `/update-constellation`, `/submit-report`, etc.).
- Basic security headers (Helmet) and rate limiting have been added to help mitigate common web attacks.
- `/process-words` proxies to the Flask service; keep it running.
## User Guide

### Getting Started

#### Sign Up
1. Open `signup.html` in your browser
2. Fill in your username, email, and password
3. Click submit
4. If email confirmation is enabled, check your email and click the confirmation link

#### Login
1. Open `login.html` in your browser
2. Enter your email and password
3. Click submit
4. On success, you'll be redirected to your account dashboard

### Creating Mind Maps

#### Start a New Constellation
1. From your account dashboard, click "Start a New Constellation"
2. Enter up to 10 words separated by commas (e.g., "cat, dog, apple")
3. Click "Submit"
4. The system will generate a visual constellation with connected nodes

#### Interact with Your Constellation
- **Drag nodes**: Click and drag any node to reposition it on the canvas
- **Zoom**: Use the + and - buttons to zoom in/out
- **Add related words**: Click on any node to see AI-generated suggestions, then click a suggestion to add it to your map
- **Customize appearance**: Use the style controls to change node shapes and colors

#### Save Your Work
- Click the "Save Constellation" button
- Your map is stored securely with JWT authentication

### Managing Saved Constellations

#### View Your Saved Maps
- Go to your account dashboard (`confirmation.html`)
- Scroll to "My Saved Constellations" section
- Each saved map shows a preview thumbnail

#### Edit an Existing Map
- Click the "Edit" button on any saved constellation
- This loads the map back into the editor for modifications

#### Share Your Maps
- Click the "Share" button to get a shareable link
- Others can view (but not edit) your constellation using this link

### Technical Notes

- All data is stored securely in MySQL database
- Authentication uses JWT tokens stored in browser localStorage
- AI suggestions are generated by a local Flask service using semantic analysis
- Maps are saved as JSON data structures
